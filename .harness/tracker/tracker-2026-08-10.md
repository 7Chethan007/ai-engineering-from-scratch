## Key concepts learned
- **GPU async execution**: `a_gpu @ b_gpu` is submitted and Python returns immediately; `torch.cuda.synchronize()` is mandatory before reading the clock, or GPU time reads ~0.
- Matrix multiplication is the single most expensive op in deep learning — every layer is built on it.
- **VRAM rules of thumb** (per-parameter bytes): fp32 = 4B → 1 GB per 1B params; fp16 = 2B → 0.5 GB per 1B; int8 = 1B; int4 = 0.5B.
- 24 GB VRAM fits ~**12B params** in fp16 (weights only, inference).
- **Training is ~6-8x heavier**: Adam optimizer + gradients ≈ 12–16 bytes/param → a 24 GB card trains only ~2B params. This is *why* LoRA/QLoRA and quantization exist.
- KV cache, activations, and framework overhead eat VRAM beyond weights.
